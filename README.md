## 🌟 核心功能全览

### 1. 🌐 现代智能双模浏览器
* **多标签页卡片式管理**：提供类似于移动操作系统的卡片式标签管理（Tab Overview）界面，支持快速新建、一键全部关闭、滑动删除标签，各标签页相互隔离独立的 WebView 实例，保证多任务浏览的稳定性与隐私性。
* **四大主流引擎极速切换**：内置 **Baidu、Bing、Google、Sogou** 四大主流搜索引擎，点击输入框左侧图标即可一键无缝切换。
* **极速联想词建议**：基于搜索联想词接口，内置 **150ms 智能防抖（Debounce）过滤** 算法，有效减少冗余网络开销，键盘输入即刻流畅呈现联想结果。
* **Edge 级硬件加速深色模式 (ForceDark)**：区别于简单粗暴的 CSS 反色滤镜，应用采用系统级 ForceDark 硬件加速技术，仅针对刺眼的浅色背景进行深色反转，对网页中的图片、视频色彩不做扭曲失真，夜间浏览护眼舒适。
* **电脑版 / 手机版排版一键切换**：自由切换 User-Agent，快速在移动端视图和桌面版（Desktop Mode）网页排版之间平滑过渡。
* **Edge 风格长按链接上下文菜单**：长按网页链接即可呼出悬浮菜单，支持“在新标签页打开”、“后台打开”、“复制链接”、“复制文本”、“直接下载”与“系统调用分享”。

---

### 2. ☁️ 云端账号体系与多端同步 (Supabase Auth & Database)
* **双模极速鉴权**：
  * **邮箱验证码免密登录 (OTP / Magic Link)**：集成自定义 SMTP 高速发信通道，输入邮箱即可秒获 6 位动态验证码；
  * **账户密码登录**：支持传统密码注册与登录，并提供忘记密码一键重置功能；
  * **第三方账号扩展**：架构上无缝兼容 Google、GitHub、Microsoft / Azure 快捷社交登录。
* **云端书签秒级双向同步**：本地书签的新增、修改与删除操作自动秒级同步至 Supabase 云端 PostgreSQL 数据库；跨设备登录即可自动合并最新数据。
* **专属资料与个性化资产**：内置丰富艺术头像库，支持系统相册本地头像自定义裁切导入，支持一键生成随机专属中文昵称，多端同步识别。
* **智能降级容灾 DNS (SmartDns)**：针对国内复杂移动网络环境（如系统 Private DNS 阻断或抖动），底层 OkHttp 网络层内置 Cloudflare Anycast 智能降级直连解析，保障在任何弱网或 DNS 异常状态下云端登录与同步均能稳定触达。

### 3. 🎨 极致动效与现代视觉交互 (Fluid Motion & Polish)
* **纯黑画布无缝交接转场**：未登录点击进入账号登录页面时，全屏平滑渐变到 `#141316` 纯黑遮罩；在纯黑掩护下挂载登录页面并退出菜单，配合登录首帧同色黑屏画布与“G-BROWSER”品牌字样无缝衔接，随后如波浪般垂落展开登录表单，**实现 0 闪烁、0 缝隙的工业级视觉转场**。
* **纯白呼吸光感转场**：登录成功后的界面切换引入了柔和的纯白呼吸光感过渡，自然点亮展开浏览器主页。
* **像素级组件对齐**：验证码输入框与“获取验证码”按钮高度完全一致（56.dp 严格对齐），彻底消除传统表单中按钮高于输入框的突兀感。
* **触控与动画性能优化**：底部导航栏支持全单元格触控判定；所有滑入/滑出面板均采用 `graphicsLayer { translationY = ... }` 硬件位移渲染，面板关闭瞬间立即交还触控权，操作零迟滞。

### 4. 📱 深度系统集成与外部调用支持
* **默认浏览器认证与一键设置**：
  * 全面适配 Android 10+ 的 `RoleManager.ROLE_BROWSER` 规范，支持一键唤起系统标准“设置为默认浏览器”对话框；
  * 深度适配各大国产手机厂商系统（Vivo OriginOS、小米 HyperOS / MIUI、华为 HarmonyOS、OPPO ColorOS 等），当系统无标准弹窗时自动智能降级跳转至系统的“默认应用管理”页面；
  * 设置页面实时检测当前是否已被设为系统默认浏览器，并展示动态状态标识。
* **外部文件智能接管与独立任务栈 (DeepLink & Intent Routing)**：
  * **独立单任务栈运行**：在系统文件管理器中点击 `.html` / `.htm` 文件选择 G-Browser 打开时，采用 `launchMode="singleTask"` 与专属 `taskAffinity`，在多任务卡片中显示为独立的 G-Browser 应用，绝不寄生或依附在文件管理器的进程中。
  * **APK 智能接管与安全安装**：当从文件管理器或网页中误点 `.apk` 安装包文件时，应用智能拦截二进制解析，自动调起 Android 系统的 `PackageInstaller` 完成安全安装流程，彻底杜绝 WebView 将安装包解析为乱码的问题。
  * **强制 UTF-8 编码修复**：WebView 全局强制启用 UTF-8 文本解析编码，从根源上消除因编码不规范引起的网页字符乱码。

### 5. 🎬 个性化动态壁纸与能耗智能优化
* **超清媒体壁纸库**：内置 15 张超清艺术静态壁纸与 10 个高清循环视频壁纸，支持在设置与主页间自由切换，让主页背景鲜活灵动。
* **本地相册自定义导入**：支持调用系统相册选择器，允许用户导入手机本地的任意图片或视频作为主页背景。
* **智能休眠与极致能耗优化**：
  * **后台自动挂起**：当 App 退到系统后台时，视频壁纸解码器 (ExoPlayer) 自动暂停解码，回到前台时自动恢复。
  * **遮挡智能休眠**：当呼出底部菜单、历史记录、书签或系统设置等任何半屏/全屏遮罩层时，后台视频壁纸立刻暂停渲染，完全释放 CPU 和 GPU 算力，保障前台交互动画以 120Hz 极限帧率丝滑呈现；遮罩层关闭后视频即刻恢复播放。

### 6. 🎵 极简音乐播放器与双语独立歌词
* **前台音乐保活服务 (MusicService)**：基于 Jetpack Media3 ExoPlayer 构建音乐播放服务，以系统 Foreground Service 形式运行，确保在后台播放时不受系统内存清理策略影响。
* **定制化通知栏遥控器**：利用 RemoteViews 深度定制通知栏控制卡片（提供折叠 COLLAPSED 与展开 EXPANDED 两种模式），展示高清唱片背景、歌名、歌手，并支持在通知栏或系统锁屏直接控制播放/暂停、上一首、下一首和停止。
* **双语独立时间轴 LRC 对齐**：支持原歌词与翻译歌词两条独立的时间轴对齐。当音乐播放到特定毫秒时，歌词才同步高亮显示，未达到时间的歌词保持空白。
* **人声提前预读优化**：内置 300ms 歌词预读缓冲算法，完美解决因网络延迟或音频解码造成的人声与歌词显示滞后问题。
* **主页悬浮歌词挂件 (重组隔离技术)**：利用 Compose 延迟状态提供者（Lambda State Provider）设计，歌词在播放滚动时，仅在 `HomeScreenLyrics` 内部进行极小范围的 Text 重绘，主页其他静态组件及搜索框实现 **0 次重复渲染**，极大降低耗电量。
* **播放进度与记忆恢复**：每次退出应用时，系统会自动将当前的播放歌曲、播放列表、以及精确的进度毫秒值持久化保存。下次打开应用时，播放器会自动恢复到上次的歌曲与进度状态，实现无缝断点续播。

---

### 7. 🌤️ 地理定位与实时天气问候
* **高精度 GPS 定位**：集成系统 `fusedLocationClient` 定位服务，在获取用户位置授权后，自动读取当前高精度经纬度。
* **三层容灾天气获取机制**：
  1. **首选 GPS 实时天气**：基于当前经纬度调用天气 API 获取当前的温度与天气状况；
  2. **第二层降级（默认城市）**：定位失败或网络超时，自动尝试获取默认城市（北京）的实时天气；
  3. **第三层降级（安全默认值）**：若全部接口故障，自动加载安全预设天气值（北京，22°C，晴），确保主页天气组件在任何恶劣环境下均不发生闪退。
* **动态天气 Emoji 适配**：根据获取到的天气状态描述（如晴、云、阴、雨、雪、雷、雾等），自动匹配显示相对应的灵动 Emoji 图标（如 ☀️, ☁️, 🌧️, ❄️, ⚡ 等）。
* **时间段个性问候**：根据当前系统时间自动匹配不同时段的贴心问候文本（如“早上好”、“中午好”、“下午好”、“晚上好”、“夜深了”）。

---

### 8. 📥 自研高并发下载管理器
* **OkHttp 并发下载内核**：抛弃了系统不稳定的 DownloadManager，采用 OkHttp 自研高并发下载引擎，支持大文件与音乐的极速下载。
* **实时下载看板**：可视化下载界面，实时计算并显示下载速度（KB/s、MB/s）、当前已下载字节数/总大小、下载进度条百分比，以及下载状态（进行中、暂停、已完成、失败）。
* **下载去重保护**：在开始下载前自动扫描本地文件，如发现同名文件已下载完成，则弹出覆盖/直接打开提示，避免重复消耗流量。
* **自定义存储路径**：支持使用 Android 存储访问框架 (SAF / Document Tree URI) 选择自定义的**音乐下载路径**与**普通文件下载路径**，适配不同手机的存储管理习惯。

---

### 9. 🔒 安全隐私与深度清理
* **细粒度 Cookies 控制**：提供全局 Cookie 开关；并可展示所有已保存 Cookie 的网站域名，支持针对单个域名进行 Cookie 删除。
* **存储深度清理**：
  * 实时计算并展示应用的 Cache 缓存、临时文件及代码缓存的物理占用大小；
  * 一键清理不仅删除本地缓存文件，还会彻底清空 WebView 的内部浏览缓存、WebStorage 数据库，并一键注销 Cookie 管理器中的全部登录状态，确保个人隐私绝对安全。
